# TS Online Classic - Warlords Database & Comparison Tool

ฐานข้อมูลและระบบเปรียบเทียบขุนพลเกม TS Online Classic (ฉบับสมบูรณ์ 100%)
- **จำนวนขุนพล**: 1,290 ตัว
- **ข้อมูล**: ธาตุ, เลเวล, สเตตัส, สกิล 4 ช่อง, SP, เป้าหมาย, คอมโบ, เอฟเฟกต์
- **รูปขุนพล**: Frame Stance ตรงตามฐานข้อมูลเกม 100%

## วิธีการ Deploy ขึ้น GitHub Pages ฟรีใน 1 นาที
1. นำไฟล์และโฟลเดอร์ทั้งหมดใน `dist/` นี้อัปโหลดขึ้น GitHub Repository ของคุณ (เช่น `ts-classic-db`)
2. เข้าไปที่เมนู **Settings** ของ Repository บน GitHub
3. ไปที่หัวข้อ **Pages** (แถบเมนูด้านซ้าย)
4. ในส่วน **Build and deployment > Branch**:
   - เลือก Branch: `main` (หรือ `master`)
   - เลือก Folder: `/ (root)`
5. กด **Save** รอประมาณ 30 วินาที จะได้ลิงก์เว็บไซต์ เช่น `https://<username>.github.io/ts-classic-db/` ให้ทุกคนสามารถเข้าใช้งานได้ทันที!
